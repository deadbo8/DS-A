## 📦 Packages & Modules

### 🔹 `recursion`
- **Focus:** Call stack mechanics, base condition formulation, recursive relations, and recursive array manipulation.
- **Key Concepts Covered:**
  - Call stack visualization (pre-recursive vs. post-recursive execution)
  - Mathematical & numerical recursion (factorials, Fibonacci sequence, logarithmic power)
  - Recursive array processing (sorted array validation, linear search from front/back, index collection)
- **Complexity Patterns:** Linear recursion ($O(n)$ time & stack space), Divide-and-conquer exponentiation, and branching recursion trees.

## 🛠️ How to Run Locally

### Prerequisites
- Java Development Kit (JDK 17 or higher recommended)
- Git

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/deadbo8/DS-A.git
   cd DS-A
   ```
2. Compile and run any package module:
   ```bash
   javac -d out src/<package-name>/*.java
   java -cp out <package-name>.<ClassName>
   ```
